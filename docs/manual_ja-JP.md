# PCジャンクファイル自動クリーナー · 使用手順書（日本語）

## 1 はじめに

### 1.1 目的

本書は「PCジャンクファイル自動クリーナー」アプリケーションのユーザーマニュアルです。本ソフトウェアの各機能と操作方法を素早く理解し、習得できるよう支援します。

### 1.2 背景

本ソフトウェアは杜宏熙によって開発されました。現在、パソコンのストレージがいっぱいになりがちで、ジャンクをクリーニングするには様々なソフトをダウンロードする必要があり、操作が面倒でメモリも占有してしまいます。そこで、わずか約 20 MB の本アプリケーションを開発しました。素早くダウンロード・インストールしてジャンクをクリーニングでき、素早くアンインストールもでき、PCのストレージ容量を占有しません。

## 2 ソフトウェア概要

### 2.1 目標

ユーザーがアプリケーションの使用方法を素早く習得し、ジャンククリーニングを迅速に行い、Cドライブの占有容量を削減できるようにします。

### 2.2 機能概要

- **ジャンクファイルのスキャン開始**：素早くスキャンとクリーニングを開始できます
- **提案とフィードバック**：アプリケーションに関する問題をフィードバックできます
- **使い方を知る**：簡単なクイックスタートガイド

## 3 動作環境

### 3.1 ハードウェア

通常のパソコンであれば問題ありません。

### 3.2 ソフトウェア

- Windows 10/11 x64
- Edge WebView2 ランタイム（Windows 11 および比較的新しい Windows 10 には内蔵されています。不足している場合はインストールスクリプトが自動的にダウンロードしてインストールします）
- Python は不要 —— PyInstaller がインタープリターと依存関係を単一の `c-clean.exe`（約 20 MB）に同梱しています

## 4 入手とインストール

### 4.1 ワンクリックインストール（推奨）

Windows PowerShell で以下を実行します：

```powershell
irm https://cdn.jsdelivr.net/gh/mianmianMilkCandy/clean@main/install-github.ps1 | iex
```

（中国大陸以外のネットワークでは `irm https://raw.githubusercontent.com/mianmianMilkCandy/clean/main/install-github.ps1 | iex` も利用できます）

スクリプトは自動的にダウンロード・インストールを行い、`c-clean` コマンドを登録し、スタートメニューにショートカット「C盘垃圾清理」を作成し、WebView2 ランタイム（不足時）をインストールして、アプリケーションを直ちに起動します。

### 4.2 起動方法（いずれかを選択）

1. 新しいターミナルを開き、`c-clean` と入力
2. スタートメニューで「C盘垃圾清理」を検索
3. 直接実行：`%LOCALAPPDATA%\Programs\c-drive-cleaner\c-clean.exe`

## 5 使用説明

### 5.1 ジャンクファイルのスキャン

1. アプリケーション起動後、ホーム画面の3つの機能入口が縦方向中央に配置されています。
2. 「开始扫描电脑垃圾文件」（スキャン開始）ボタンをクリックすると、スキャン画面に移動します。
3. スキャン画面で「确定」（確認）ボタンをクリックするとスキャンを開始します。
4. スキャンには約 10～20 秒かかり、進行状況バーに現在スキャン中のディレクトリとパーセンテージがリアルタイムで表示されます。
5. 「返回」（戻る）ボタンをクリックするとホームに戻りますが、スキャンは中断されません。スキャンが完了すると、自動的にクリーニング画面に移動します。
6. クリーニング画面では、Cドライブ全体の容量、空き容量、使用容量、ジャンク占有量の概要が表示されます。

### 5.2 ジャンクファイルのクリーニング

1. コアコードはシステムのジャンクパスを保護しています。デフォルトで未チェックのパスは自動的に保護されているためです。どうしてもクリーニングしたい場合は、手動でチェックできます。
2. 「开始清理」（クリーニング開始）をクリックすると、確認ダイアログが表示されます。
3. 確認するとクリーニングが開始され、完了後は自動的にホーム画面に戻ります。

### 5.3 権限について

クリーニング実行後に一部のパスで「権限不足」や「アクセス拒否」の問題が発生した場合は、プログラム起動前に右クリックして「管理者として実行」で権限を昇格させてください：

- 権限昇格なし：一部のシステムディレクトリ（システムログ、Windows Update キャッシュなど）のクリーニングはスキップされます
- 権限昇格済み：これらのディレクトリは正常にクリーニングできます

クリーニング前に WeChat、QQ、ブラウザを終了することをお勧めします。ファイルが占有されてクリーニング失敗になるのを防げます。

### 5.4 提案とフィードバック

「建议与反馈」（提案とフィードバック）をクリックすると、フィードバックページに入り意見を送信できます。「返回」（戻る）でホーム画面に戻れます。

### 5.5 使い方を知る（初心者ガイド）

「了解使用」（使い方を知る）ボタンをクリックすると、簡単な使用ガイド（クイックスタート入口を指す矢印案内）が表示されます：

「跳过指引」（ガイドをスキップ）をクリックし、一番下の「快速开始」（クイックスタート）をクリックすれば、スキャンとクリーニングの画面に入れます。

## 6 よくある質問

| 問題 | 原因と解決策 |
|---|---|
| ウィンドウが空白 | Edge WebView2 ランタイム不足。再インストール（自動インストールされます）またはマイクロソフト公式サイトから手動インストール |
| 一部ディレクトリで権限不足 | 管理者としてプログラムを実行 |
| WeChat/QQ ディレクトリのクリーニング失敗 | 先に WeChat/QQ を終了してからクリーニング（ファイル使用中） |
| システム重要ディレクトリがスキップされる | 安全設計：System32、Program Files などは保護対象 |

## 7 アンインストール

リポジトリの `uninstall.ps1` を実行するか、手動で以下を削除してください：

- `%LOCALAPPDATA%\Programs\c-drive-cleaner` ディレクトリ
- スタートメニューのショートカット
- ユーザー PATH 内のインストールディレクトリのエントリ

# 电脑垃圾文件自动清理应用程序 · 使用手册（简体中文）

## 1 引言

### 1.1 编写目的

本文档是为「电脑垃圾文件自动清理应用程序」编写的用户操作手册，旨在帮助用户快速了解并掌握该软件的各项功能与操作方法。通过本文档，用户能够熟悉软件的使用流程。

### 1.2 背景

本软件由杜宏熙开发。当下人们的电脑存储空间常常变得爆满，想要清理垃圾又需要下载各式各样的软件，操作繁琐还占用内存。为此开发这款仅仅约 20 MB 的应用程序，以方便用户快速下载安装、清理垃圾，也能快速卸载，不占用用户电脑存储空间。

## 2 软件概述

### 2.1 目标

使用户能够快速掌握应用程序的使用方法，快速进行垃圾清理，减少 C 盘占用空间。

### 2.2 功能概述

- **开始扫描电脑垃圾文件**：点击可以快速开始扫描和清理
- **建议与反馈**：若有该应用程序的使用问题可以进行反馈
- **了解使用**：简易的快速开始引导

## 3 运行环境

### 3.1 硬件

普通电脑即可。

### 3.2 软件

- Windows 10/11 x64
- Edge WebView2 运行时（Win11 及较新 Win10 已内置；缺失时安装脚本会自动下载安装）
- 无需 Python —— PyInstaller 已将解释器和依赖打进单个 `c-clean.exe`（约 20 MB）

## 4 获取与安装

### 4.1 一键安装（推荐）

在 CMD 或 PowerShell 中均可执行：

```powershell
powershell -Command "iex (irm 'https://cdn.jsdelivr.net/gh/mianmianMilkCandy/clean@main/install-github.ps1')"
```

> 提示：`irm ... | iex` 简写仅适用于 PowerShell；在 CMD 中会提示「irm 不是内部或外部命令」。上面的 `powershell -Command "..."` 形式在 CMD、PowerShell、Win+R 运行框中通用。

（纯 PowerShell 亦可用 `irm https://cdn.jsdelivr.net/gh/mianmianMilkCandy/clean@main/install-github.ps1 | iex`；海外网络可把域名换为 `raw.githubusercontent.com`）

脚本自动完成下载、安装、注册 `c-clean` 命令、创建开始菜单快捷方式「C盘垃圾清理」、检测并安装 WebView2 运行时（如缺失），并立即启动应用。

### 4.2 启动方式（任选其一）

1. 新开一个终端，输入命令：`c-clean`
2. 开始菜单搜索「C盘垃圾清理」
3. 直接运行：`%LOCALAPPDATA%\Programs\c-drive-cleaner\c-clean.exe`

## 5 使用说明

### 5.1 扫描垃圾文件

1. 进入应用程序后，主页三个功能入口纵向居中排列。
2. 点击「开始扫描电脑垃圾文件」按钮，快速转跳到扫描界面。
3. 在扫描界面点击「确定」按钮开始扫描垃圾文件。
4. 扫描过程约 10–20 秒，进度条实时显示当前扫描目录与百分比。
5. 此时点击「返回」按钮可回到主页，但并不会打断扫描；扫描完毕会自动转跳到清理界面。
6. 清理界面会总览整个用户 C 盘的空间、剩余空间、占用空间以及垃圾占用用量。

### 5.2 清理垃圾文件

1. 核心代码文件对系统垃圾文件进行了保护，默认未勾选的路径是因为自动进行保护；若用户执意清理，可以自行勾选。
2. 点击「开始清理」会弹出确认清理选项框。
3. 确认后即开始清理，清理完毕会自动返回主页。

### 5.3 权限说明

倘若点击确认清理垃圾后出现部分路径「权限不足」或「拒绝访问」的问题，可以在启动程序之前右键点击「以管理员身份运行」进行提权：

- 未提权时：部分系统目录（如系统日志、Windows 更新缓存）清理会被跳过
- 已提权后：这些目录可以正常清理

建议清理前退出微信、QQ 和浏览器，避免文件被占用导致清理失败。

### 5.4 建议与反馈

点击「建议与反馈」可以进入建议与反馈页面填写并提交；点击「返回」可回到主页。

### 5.5 了解使用（新手引导）

点击「了解使用」按钮会弹出简易使用引导（箭头指引快速开始入口）：

此时点击「跳过指引」，再点击最下方的「快速开始」，同样可以进入开始扫描和清理垃圾文件的页面。

## 6 常见问题

| 问题 | 原因与解决 |
|---|---|
| 窗口空白 | 缺少 Edge WebView2 运行时，重装时会自动安装；或手动从微软官网安装 |
| 部分目录权限不足 | 以管理员身份运行程序 |
| 微信/QQ 目录清理失败 | 先退出微信/QQ 再清理（文件被占用） |
| 系统关键目录被跳过 | 安全设计，System32、Program Files 等受保护目录不参与清理 |

## 7 卸载

CMD 或 PowerShell 中均可执行一键卸载：

```powershell
powershell -Command "iex (irm 'https://cdn.jsdelivr.net/gh/mianmianMilkCandy/clean@main/uninstall-github.ps1')"
```

纯 PowerShell 环境也可用简写：

```powershell
irm https://cdn.jsdelivr.net/gh/mianmianMilkCandy/clean@main/uninstall-github.ps1 | iex
```

脚本自动完成：停止运行中的程序 → 删除 `%LOCALAPPDATA%\Programs\c-drive-cleaner` 目录 → 从用户 PATH 移除安装目录 → 删除开始菜单快捷方式。Edge WebView2 为系统共享组件，将保留。重复执行安全无副作用。

也可手动删除：

- `%LOCALAPPDATA%\Programs\c-drive-cleaner` 目录
- 开始菜单快捷方式「C盘垃圾清理」
- 用户 PATH 中的安装目录条目
